# iAuto.kz — сайт подбора автозапчастей

Лендинг, собранный один в один по макету Figma (Frame 117, 1200px), с адаптивом под планшет и телефон и рабочим приёмом заявок.

## Структура

```
index.html          главная страница
privacy.html        политика конфиденциальности (шаблон)
terms.html          пользовательское соглашение (шаблон)
offer.html          публичная оферта (шаблон)
admin.html          просмотр заявок (нужен запущенный сервер и ADMIN_TOKEN)
css/style.css       стили сайта
css/doc.css         стили документов и админки
js/config.js        контакты, ссылки на мессенджеры, адрес API  ← правьте здесь
js/main.js          логика: меню, модалки, аккордеоны, маска телефона, отправка форм
assets/img/         оптимизированные изображения (original/ — исходники из макета)
server/             Node.js-сервер: раздача сайта + приём заявок + Telegram
```

## Быстрый старт

Без сервера сайт работает как статика: откройте `index.html` в браузере. Формы в этом режиме
отправляют заявку в WhatsApp с уже заполненным текстом.

С сервером (заявки сохраняются и приходят в Telegram):

1. Установите Node.js 18+ с https://nodejs.org
2. В папке `server`:

```bash
npm install
```

3. Скопируйте `server/.env.example` в `server/.env`, заполните `ADMIN_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
4. Запустите:

```bash
npm start
```

5. Откройте http://localhost:3000. Заявки: http://localhost:3000/admin.html

## Что настроить перед публикацией

- `js/config.js` — реальный телефон, номер WhatsApp, ник Telegram и Instagram, e-mail, ссылка на карту.
- Тексты в `privacy.html`, `terms.html`, `offer.html` — проверить с юристом, вписать реквизиты.
- Кейсы «Примеры работ» — описания в `js/main.js` (объект `CASES`) и карточки в `index.html`.

## Функционал

- Липкая шапка, подсветка активного раздела, мобильное меню.
- Все кнопки CTA открывают модальную форму (для продавцов — вариант с полем «Магазин»).
- Кнопки «Подробнее» в кейсах открывают карточку кейса с деталями и экономией.
- Аккордеоны «Продавцам» и FAQ с ответами.
- Маска телефона +7 (___) ___-__-__, фильтр VIN (17 символов), проверка полей и согласия.
- Отправка заявки на `/api/lead`; при недоступности сервера — автоматический переход в WhatsApp.
- Сервер: сохранение в `server/data/leads.json`, уведомление в Telegram, защита от спама, выгрузка CSV в админке.
